 # Libro Interactivo: Cuidado del Agua

* Descripción del proyecto

Este proyecto consiste en el desarrollo de un libro interactivo educativo sobre el cuidado del agua, realizado en Java utilizando interfaces gráficas con Swing.

El programa busca promover el aprendizaje sobre la importancia del agua, su uso responsable y las acciones que se pueden realizar para proteger este recurso.

* Objetivo

Desarrollar una aplicación interactiva que permita al usuario leer información educativa, navegar entre páginas y realizar una actividad de evaluación relacionada con el cuidado del agua.

* Tecnologías utilizadas

- Java.
- Java Swing.
- Apache NetBeans.
- Maven.
- Git y GitHub.

* Estructura del proyecto

El proyecto está organizado utilizando el patrón Modelo-Vista-Controlador (MVC):

- Modelo: contiene las clases encargadas de representar y gestionar la información del libro, sus páginas y preguntas.
- Vista: contiene la interfaz gráfica con la que interactúa el usuario.
- Controlador: coordina las acciones del usuario entre la interfaz gráfica y el modelo.

* Funcionalidades previstas

- Presentación de la portada del libro.
- Navegación entre páginas informativas.
- Acceso a una actividad educativa.
- Registro y evaluación de respuestas.
- Control de intentos.
- Visualización de resultados.
- Regreso al menú principal.
- Opción para salir del programa.

* Ejecución

El proyecto puede abrirse desde Apache NetBeans como un proyecto Maven.

1. Abrir NetBeans.
2. Seleccionar "Open Project".
3. Ubicar la carpeta del proyecto.
4. Esperar a que Maven cargue las dependencias.
5. Ejecutar el proyecto desde el IDE cuando la integración de las clases esté finalizada.
