Tarea 4: Libro Interactivo, Fundamentos de Programación**

Libro Interactivo: Cuidado del Agua

Descripción del proyecto

Desarrollamos un libro interactivo educativo sobre el cuidado del agua utilizando Java y Swing. El programa permite al usuario conocer la importancia del agua, los efectos de la contaminación y algunas prácticas para conservar este recurso natural.

Tecnologías utilizadas

- Java.
- Java Swing.
- Apache NetBeans.
- Maven.
- Git y GitHub.

Estructura del proyecto

Organizamos el proyecto mediante el patrón Modelo-Vista-Controlador (MVC):

- Modelo: Gestiona la información del libro, sus páginas, preguntas y resultados.
- Vista: Presenta las interfaces gráficas y permite al usuario interactuar con el programa.
- Controlador: Conecta el modelo y las vistas, y gestiona las acciones del usuario.

Principales clases

- Libro: Administra las páginas, las preguntas, los intentos y los resultados.
- Pagina: Define la estructura base de las páginas.
- PaginaInformativa: Representa las páginas con contenido educativo.
- PaginaActividad: Representa la página de la actividad.
- Pregunta: Almacena las preguntas y sus opciones de respuesta.
- ControladorLibro: Gestiona los eventos y la navegación entre las vistas.
- GUI_VistaPrincipal: Presenta la portada.
- GUI_VistaContenido1, GUI_VistaContenido2 y GUI_VistaContenido3: Presentan el contenido educativo.
- GUI_ActividadInteractiva:** Permite responder las preguntas.
- GUI_Resultados: Muestra los resultados de la actividad.
- Principal: Inicia el programa y conecta sus componentes.

Funcionalidades

- Navegación entre las páginas del libro.
- Presentación de información sobre el cuidado del agua.
- Actividad interactiva con preguntas.
- Evaluación y registro de respuestas.
- Control de intentos.
- Visualización de resultados.
- Opciones para regresar y salir del programa.

Ejecución

1. Abrir Apache NetBeans.
2. Seleccionar Open Project.
3. Buscar y abrir la carpeta del proyecto.
4. Esperar a que Maven cargue las dependencias.
5. Ejecutar el proyecto desde NetBeans.
